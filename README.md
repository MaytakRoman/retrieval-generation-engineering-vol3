# Инженерная практика систем поиска и генерации — том 3

Программное сопровождение третьего тома серии «Прикладной искусственный интеллект».
Авторы: П. А. Пылов, Р. В. Майтак, А. В. Протодьяконов.
Версия программного комплекта: 1.0.0 от 14 октября 2026 года.
Репозиторий: https://github.com/MaytakRoman/retrieval-generation-engineering-vol3

## Запуск

Проверенное окружение: Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, scikit-learn 1.8.0.
В новом виртуальном окружении установите зависимости и выполните общий запуск:

```sh
python -m pip install -r requirements.txt
python run_all.py
```

На macOS/Linux интерпретатор может называться `python3`.
Команды выполняются из корня распакованного комплекта. Для самого эксперимента
интернет, GPU, нейросетевые веса и внешние сервисы не нужны.
На Windows и macOS комплект не проверялся.

Раздельный запуск:

```sh
python reference_rag.py --output results
python tests.py
python metadata_stress.py
python numerical_checks.py
```

`run_all.py` выполняет эти четыре команды в отдельных процессах, сохраняет журналы
и дополнительно сопоставляет данные, идентификаторы, предсказания, сводные метрики и хеши.
Повторный запуск обновляет results/, execution_logs/ и execution_report.json.
Для сохранения отдельного опыта скопируйте весь комплект в новый каталог.
metadata_stress.py и numerical_checks.py записывают результаты именно в results/.

в программный репозиторий не включён.

## Результаты воспроизведения

Все четыре модуля выполнены без ошибок, шесть функциональных тестов пройдены.
На 400 тестовых вопросах правильно завершены: BM25 — 128, LSA — 256,
гибрид — 224, полный маршрут — 400, без контроля доступа — 336,
без контроля версии — 368. Числа совпали с рукописью.
Полный маршрут отвечает на 256 вопросов и корректно отказывает в 144 случаях;
он не отвечает на все 400 вопросов. В полном маршруте нет раскрытий закрытого материала.

Подбор глубины слияния использует только 200 вопросов настройки; выбрана глубина 10.
Группы оборудования настройки (0–19) и теста (20–59) не пересекаются.
В опыте метаданных изменены 120, 240 и 480 флагов; исходные документы и эталоны сохранены.
Все дополнительные проверки чувствительности являются диагностикой на прежнем тесте,
а не новым независимым подтверждением после подбора конфигурации.

## Границы интерпретации

Корпус полностью синтетический. Латентно-семантическое представление основано на SVD;
нейросетевые эмбеддинги и промышленная LLM в эксперименте не запускались.
Генератор ответа извлекает текст из выбранного документа. Идентичность оборудования,
операции и модификации устанавливается ограниченным фиксированным парсером.
Точные статусы current/restricted заданы генератором и не доказывают правильность
метаданных реального корпуса. Спецификации моделей приложения Б не являются их рейтингом.

Время в summary.json относится к ранжированию, фильтрам и извлекающему ответу
при заранее вычисленных оценках; оно не включает весь путь от текста запроса.
Длительности меняются между запусками и не являются нормативом промышленной задержки.
Данные проверяются по точным хешам; показатели и ранги необходимо сопоставлять
с учётом версии числовых библиотек и возможных близких оценок.
